# Web Research & Technical Verification Skill (On-Demand)

Activate this skill when:
- Investigating official framework/library documentation, APIs, and release notes.
- Checking breaking changes and migration steps for new versions (Spring Boot, Angular, JDK, PostgreSQL).
- Troubleshooting complex bugs, unknown exceptions, or external integration issues.

## Execution Rules
1. **Primary Sources First:** Target official documentation domains (e.g. `docs.spring.io`, `angular.dev`, `postgresql.org`, `github.com`).
2. **Compatibility Verification:** Cross-check API versions against the active repository stack before recommending code.
3. **Structured Output:**
   - **Direct Solution / Answer**
   - **Key Breaking Changes & Version Requirements**
   - **Verified Code Snippet / Configuration**
   - **Official Reference Link**
4. **Token Efficiency:** Summarize findings with high density and zero filler.
